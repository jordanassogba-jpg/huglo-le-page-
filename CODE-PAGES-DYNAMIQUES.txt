CE QUE CE CODE FAIT
  - chaque fiche Expertise émet son propre graphe JSON-LD, construit sur son
    adresse : nœud WebPage, BreadcrumbList, rattachement aux avocats de la
    matière, et la FAQ pour les deux fiches qui en portent une ;
  - og:type passe à « article » sur les Expertises et à « profile » sur les
    fiches avocats ;
  - le bloc ld+json vide et le nœud ImageObject isolé disparaissent, parce que
    setStructuredData remplace le balisage que Wix génère par défaut.

OÙ IL VA
Dans le code DE LA PAGE, pas dans celui du site. Un garde-fou est prévu dans les
deux extraits : mal collé, le code s'arrête sans rien modifier.

CE QUI EST DÉJÀ PRÊT DANS LE CMS, TU N'AS RIEN À Y FAIRE
Les douze graphes sont écrits et contrôlés : URL, @id et fil d'Ariane cohérents
sur les douze, description présente sur les douze, zéro anomalie.

ÉTAPE 1. INSTALLER LES DEUX PAQUETS
===============================================================================

Une seule fois pour le site, depuis le gestionnaire de paquets du panneau de code :

    @wix/site-seo
    @wix/site-location


===============================================================================
ÉTAPE 2. PAGE DYNAMIQUE EXPERTISES
===============================================================================

-------------------------------------------------------------------------------
import { seo } from '@wix/site-seo';
import { location } from '@wix/site-location';
import wixData from 'wix-data';

$w.onReady(async () => {
  try {
    // Reconstitue l'adresse de la fiche affichee
    // ex. /expertises/droit-urbanisme-amenagement
    const slug = '/' + [location.prefix(), ...location.path()]
      .filter(Boolean)
      .join('/');

    const res = await wixData
      .query('EXPERTISES')
      .eq('link-expertises-title', slug)
      .limit(1)
      .find();

    const item = res.items[0];

    // Garde-fou : hors d'une fiche Expertise, on ne touche a rien
    if (!item || !item.jsonldGraph) {
      return;
    }

    await seo.setStructuredData([JSON.parse(item.jsonldGraph)]);
    await seo.setMetaTags([{ property: 'og:type', content: 'article' }]);
  } catch (err) {
    console.error('Balisage JSON-LD non applique :', err);
  }
});
-------------------------------------------------------------------------------


===============================================================================
ÉTAPE 3. PAGE DYNAMIQUE AVOCATS
===============================================================================

-------------------------------------------------------------------------------
import { seo } from '@wix/site-seo';
import { location } from '@wix/site-location';

$w.onReady(async () => {
  try {
    // Garde-fou : uniquement sur les fiches avocats
    if (location.prefix() !== 'avocats') {
      return;
    }

    await seo.setMetaTags([{ property: 'og:type', content: 'profile' }]);
  } catch (err) {
    console.error('og:type non applique :', err);
  }
});
-------------------------------------------------------------------------------

bloc. Si la meta description a disparu, retire la ligne setMetaTags et garde
seulement setStructuredData, puis dis-le moi : on traitera og:type autrement.

profile.
